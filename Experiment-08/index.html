Book Collection REST API

This experiment uses Node.js and Express. GitHub Pages hosts this documentation and test console only; it cannot run the Express server.

Run the API locally

  1. Install Node.js LTS.
  2. Download server.js and package.json from this folder.
  3. Open a terminal in the folder and run npm install.
  4. Run npm start. The API runs at http://localhost:3000.

API endpoints

MethodEndpointAction
GET/api/booksList all books
GET/api/books/:idGet one book
POST/api/booksCreate a book
PUT/api/books/:idUpdate a book
DELETE/api/books/:idDelete a book
