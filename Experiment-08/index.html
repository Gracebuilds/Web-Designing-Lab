Experiment 8: Book REST API

Technology: Node.js and Express

This experiment demonstrates CRUD operations for a book collection through REST endpoints.

API endpoints

  • GET /books — retrieve all books
  • GET /books/:id — retrieve one book
  • POST /books — add a book
  • PUT /books/:id — update a book
  • DELETE /books/:id — delete a book

Run locally

  1. Install Node.js.
  2. Run npm install in the project folder.
  3. Run npm start.

For this demonstration, the server stores data in memory, so data resets when the server restarts.
