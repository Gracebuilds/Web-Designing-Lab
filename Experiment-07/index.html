Experiment 7: Notes Application

Technology: React with Vite

This experiment demonstrates a notes application where users can create, view and delete notes using React components and state.

Run the React project

  1. Open a terminal in this experiment folder.
  2. Run npm install.
  3. Run npm run dev.
  4. Open the local URL printed by Vite.

Core React idea: use component state to store the notes array and update it when a note is added or deleted.
