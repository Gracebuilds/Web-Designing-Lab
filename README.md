This repository contains the source code for Web Designing Lab Experiments 1–8. Open each experiment folder and follow its README for setup and execution.

| Experiment | Project | Main technologies |
|---|---|---|
| 01 | GitHub Pages demo | HTML, CSS, GitHub |
| 02 | Personal portfolio | HTML, CSS |
| 03 | Dynamic to-do list | HTML, CSS, JavaScript |
| 04 | SEO and accessibility page | Semantic HTML, CSS |
| 05 | Weather application | HTML, CSS, Fetch API, OpenWeather |
| 06 | Responsive blog | Bootstrap 5, CSS |
| 07 | Notes application | React, Vite |
| 08 | Book collection REST API | Node.js, Express |

## Run locally
Static experiments (01–06): open the folder's `index.html` in a browser, or use VS Code Live Server.  
Experiment 07: enter its folder, run `npm install`, then `npm run dev`.  
Experiment 08: enter its folder, run `npm install`, then `npm start`.

**Note:** Experiment 05 needs an OpenWeather API key. Do not commit a private key to this public repository. Experiment 08 is an in-memory demonstration API; its data resets when the server restarts.
