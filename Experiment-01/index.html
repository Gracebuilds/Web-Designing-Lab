Experiment 01: GitHub Repository and GitHub Pages

Set up a repository, create branches, merge changes and publish a static site.

Aim

Understand version control and publish a simple static website using GitHub Pages.

Git workflow

  1. Create a public repository and add project files.
  2. Create a feature branch for an isolated change.
  3. Commit the change and open a pull request.
  4. Review and merge it into main.
  5. Enable Pages in Settings → Pages → Deploy from a branch → main → /(root).

Resources utilized

VS Code, Git, GitHub, HTML, CSS, GitHub Pages and a browser.

Repository and live website

GitHub repository · Published website

Result

The static website is published through GitHub Pages. Branching and merging are demonstrated as repository operations.
